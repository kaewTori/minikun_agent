    PONY PROMPT FIELD GUIDE
    อยากเขียน Pony เอง? เปิดคู่มือฉบับย่อ
    คู่มือเสริม    
          
    
            
    01 · QUALITY
    เริ่มด้วย score tags
    score_9, score_8_up, score_7_up วางไว้ต้น prompt เพื่อกำหนดฐานคุณภาพของ Pony โดยไม่บังคับ source
    
            
    02 · COUNT / CHARACTER
    นับก่อน แล้วค่อยบอกตัวละคร
    1girl, solo, short black hair, green sweater ช่วยลดตัวละครซ้ำและแยกคุณลักษณะได้ชัดกว่าประโยคยาว
    
            
    03 · ACTION / EXPRESSION
    บอกมือ สายตา และการกระทำ
    holding a glass jar, looking down, gentle smile ทำให้ pose มีเจตนา ไม่ใช่เพียงยืนอยู่ในฉาก
    
            
    04 · SCENE / LIGHT
    สร้างฉากด้วยคำนามที่มองเห็น
    observatory workshop, rainy night, moonlight ตรงกว่าอารมณ์นามธรรมที่ CLIP ตีความได้กว้าง
    
            
    05 · CAMERA / EMPHASIS
    ปิดท้ายด้วยเฟรมและน้ำหนัก
    close-up, upper body, depth of field, (detailed eyes:1.15) ใช้ weight เบา ๆ และเฉพาะรายละเอียดสำคัญ
    
          
    
          
    ประโยคแบบแชต
    ผู้หญิงผมดำกำลังถือดาวในหอดูดาว ภาพสวย ๆ
    →
    PONY TAG ORDER
    score_9, score_8_up, score_7_up, 1girl, solo, short black hair, green sweater, holding a glowing glass jar, looking down, gentle smile, observatory workshop, rainy night, moonlight, anime key visual, close-up, depth of field, (detailed eyes:1.15)
    
          
    NEGATIVE แยกอีกช่อง
    score_4, score_3, score_2, score_1, worst quality, bad anatomy, bad hands, extra fingers, text, watermark
    ใส่สิ่งที่ไม่ต้องการเป็น tag ตรง ๆ ไม่ต้องเขียน “no …” และอย่านำ negative tags ไปปนกับ positive prompt
